Método

De una foto de campo a un modelo 3D

El modelo se obtiene de una sola fotografía con herramientas libres en Python. El programa está en la carpeta pipeline/ del repositorio para repetir el proceso con cada hongo.

  1. RecorteEl hongo se separa del fondo con SAM (Segment Anything), marcando puntos sobre el píleo y el estípite.
  2. PíleoLa cara superior, vista como elipse por la perspectiva, se endereza a un disco y se usa como textura.
  3. Estípite y láminasEl ancho del pie se mide fila por fila y se gira sobre su eje; las láminas se modelan con el color de su borde visible.

El modelo supone simetría radial y completa las partes que no se ven en la foto. Sirve para ver la forma y los caracteres, no para medir. Para modelos fieles se usará fotogrametría (40 a 80 fotos alrededor de cada hongo).
